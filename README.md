# ExamSystem
線上考試系統完整功能清單如下：

## 一、 線上測驗模組 (Exam Examination)
- 動態隨機抽題：依據設定參數，由後端記憶體（C# 隨機演算法）快速挑選題號，確保每位考生題目順序或內容隨機。
- 雙重倒數計時：前端 Blazor Timer 每秒更新視覺倒數；後端以伺服器時間進行二次驗證，杜絕修改瀏覽器時間作弊。
- 即時異步暫存：考生每劃記一題，系統即時（Async）寫入資料庫，遇斷線、當機，重連後可復原狀態繼續作答。
- 交卷自動閱卷：全面支援是非、單選、複選題（支援全對才給分或漏選按比例給分邏輯）之全自動無人批改。
- 視窗防弊偵測：透過 JavaScript 監聽 blur 事件，記錄並限制學生切換分頁、離開考試視窗的次數。
- 應試介面防護：鎖定滑鼠右鍵、禁止複製（Ctrl+C）及禁用 F12 開發者工具，防止題庫外流。

## 二、 考題庫管理模組 (Question Bank)
- 基礎題型維護：支援新增、修改、刪除是非題、單選題、複選題。
- 答案與解析欄位：每道題目除設定標準答案外，皆可擴充「解析/解答說明」欄位，供學生事後複習。
- 外部題庫匯入：支援上傳 Excel（如使用 MiniExcel 或 EPPlus 套件）或 CSV 檔案，進行批次題目快速匯入。
- 多媒體題目支援：題目內容與選項支援圖片、音檔 URL，以便未來擴充看圖辨識或聽力測驗。
- 題庫版本控制：修改舊題目時產生新版本號，確保已被考過的歷史試卷內容與成績不會遭到竄改。

## 三、 考試與系統設定模組 (Exam Configuration)
- 時間自訂策略：內建 20、30、60、90 分鐘快捷選項，並支援自訂任意分鐘數（如：120 分鐘）。
- 題型混合配分：可自訂單場考試之是非題抽題數、選擇題抽題數，或設定兩者混合隨機出題。
- 考試效期排程：可設定考卷的「開放起訖時間區間」（例如：週五 14:00 - 16:00 開放登入應試）。
- 特殊彈性設定：後台可針對特定學生（如補考、特殊生）單獨延長作答時間或開放重複挑戰權限。

## 四、 成績與數據分析模組 (Dashboard & Analytics)
- 個人歷史成績：學生可查詢過去所有參與過的測驗紀錄、得分、交卷時間。
- 錯題動態複習：系統自動撈取該場考試答錯的 ExamDetail 明細，顯示學生盲點、正確答案與題目解析。
- 成績統計儀表板：提供教師與系統管理員檢視全班及格率、最高分、最低分、平均分等即時圖表。
- 試題鑑別度分析：自動統計各題目的「答錯率/答對率」，協助出題者評估題目難易度是否合理。
- 數據報表匯出：成績數據與錯題統計可一鍵匯出為 Excel 或 PDF 檔案，方便行政存檔。

## 五、 安全與角色權限模組 (Identity & RBAC)
- 三層角色授權：基於 ASP.NET Core Identity 實作系統管理員（全功能）、教師（題庫與成績）、學生（應試與複習）權限。
- 班級群組綁定：考卷可指定特定班級、部門或群組才能應試，非受邀帳號無法進入測驗。


# 系統角色
>## 管理員 (Admin)
- 系統維護
- 題庫管理
- 建立考試
- 成績查詢
- 使用者管理
>## 教師 (Teacher)
- 維護題庫
- 建立考卷
- 查閱成績
- 錯題分析
>## 學生 (Student)
- 參加考試
- 查看成績
- 錯題複習
